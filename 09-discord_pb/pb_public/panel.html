    Direct database API

    Use a PocketBase superuser token with POST api/discord/import. Send the same normalized JSON batch used here:

    {"messages": [{
  "message_id": "…",
  "channel_id": "…",
  "author_id": "…",
  "ts": "2026-09-06T00:00:00Z",
  "content": "…"
}]}

    IDs must be strings containing 17–20 digits. Optional fields include thread_id, guild_id, author_name, attachments_json, embeds and raw. No raw SQL access or unauthenticated writes.

    GET api/collections/discord_messages/records reads messages. GET api/collections/discord_entities/records resolves names. Both require authentication.

    Stored in this add-on’s PocketBase. Message content is displayed as text, never executed.
